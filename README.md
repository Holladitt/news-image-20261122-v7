# The World in One Day — 22 November 2026

[![make.fun](https://make.fun/bounty/news-image-20261122/badge)](https://make.fun/bounty/news-image-20261122)
[![make.fun](https://make.fun/bounty/news-image-20261122/badge/dev)](https://make.fun/bounty/news-image-20261122)
[![make.fun](https://make.fun/bounty/news-image-20261122/badge/entry)](https://make.fun/bounty/news-image-20261122)

A one-page broadsheet that sums up Sunday 22 November 2026 in 35 dated stories
across 7 regions: a giant serif date, a numbers strip, a UTC timeline, three
labelled scene leads (COP31, Bahrain, Kyiv), twelve illustrated secondaries, a
dotted world map, an ALSO list, and a red DATE CHECK box that names the
other-day news left out on purpose.

The image is drawn in code (`gen.py`, Pillow, no network) and copied to
`/output/entry.png` by `main.py`. Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
